# Um Tostão (Minhas Despesas)

App pessoal de controle de gastos (PWA). Entra com e-mail e senha ou Google (Supabase); os dados ficam no aparelho e são sincronizados com a conta de cada pessoa (esquema em `supabase/sync.sql`). Nenhum dado pessoal vem para este repositório.

Abra no Safari do iPhone → Compartilhar → Adicionar à Tela de Início.
